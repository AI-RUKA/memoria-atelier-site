# MEMORIA material assets

Decorative source materials for the MEMORIA atelier landing page.

These are web-optimized copies of the supplied artwork. UI placement is intentionally not defined here so the next UI pass can use them freely.

## Files

- `cookie-leaf.webp` — round leaf cookie
- `cookie-rename.webp` — rename / pencil cookie
- `memoria-cookie.webp` — MEMORIA flower cookie plaque
- `floral-wreath.webp` — oval floral wreath cookie
- `glass-drop-a.webp` / `glass-drop-b.webp` — clear droplet accents
- `floral-paper.webp` — torn floral paper
- `gingham-paper.webp` — green gingham torn paper
- `botanical-paper.webp` — tan botanical torn paper
- `books-ornament.webp` — embroidered books ornament
- `flower-brooch.webp` — ornate blue-flower brooch
- `glass-blob.webp` / `glass-circle.webp` — clear glass accents
- `ai-assisted-badge.webp` — AI ASSISTED badge
- `couple-stamp.webp` — illustrated couple postage-stamp motif
- `small-memo.webp` — ornate cream memo frame
- `translucent-note-floral.webp` — translucent floral note
- `translucent-note-torn.webp` — translucent torn note
